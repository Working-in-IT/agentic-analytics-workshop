Подготовка к воркшопу

Установите Python, git, VS Code и Claude Code, склонируйте оба репо и проверьте, что всё работает.

⚠ Пройдите чек-лист за день до воркшопа — на эфире времени на установку не будет

За 30–45 минут с нуля · 5 минут, если уже всё стоит

  1. Python 3.11+ — для запуска скиллов rich-репо
  2. Git — чтобы склонировать репозитории
  3. VS Code с расширением Claude Code
  4. Активная подписка Claude (Pro / Max / Team / Enterprise) или API-доступ
  5. Склонированы оба репо — fitflow-bare и fitflow-rich
  6. Smoke test пройден — Claude отвечает, SQLite-база читается
1

Python 3.11+

Проверьте, что уже стоит:

python3 --version

Если выводит Python 3.11.x или новее — переходите к шагу 2. Если младше — установите через Homebrew:

# Установка Homebrew, если его нет
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Установка Python
brew install python@3.12
2

Git

Проверка: git --version. Если не установлен:

brew install git

Альтернатива — Xcode Command Line Tools (включают git):

xcode-select --install
3

VS Code + расширение Claude Code

Установите VS Code:

brew install --cask visual-studio-code

Или скачайте с code.visualstudio.com.

Откройте VS Code, перейдите в Extensions (Cmd + Shift + X), найдите Claude Code от Anthropic и нажмите Install.

Альтернатива через терминал: code --install-extension anthropic.claude-code
4

Доступ к Claude

Нужна активная подписка Claude (Pro / Max / Team / Enterprise) или API-ключ. Оформить подписку: claude.ai/upgrade. API-ключ — на console.anthropic.com.

Откройте панель Claude Code в боковой панели VS Code. При первом запуске:

  • С подпиской — нажмите Sign in with Claude
  • С API-ключом — выберите Use API key и вставьте
Если в компании уже подключён Claude или Anthropic API — спросите у руководителя про корпоративный доступ, не надо платить из своего кармана.
5

Клонируйте оба репо

В терминале выберите папку для проектов и клонируйте оба репозитория:

cd ~/Projects   # или любая другая папка

git clone https://github.com/Working-in-IT/fitflow-bare.git
git clone https://github.com/Working-in-IT/fitflow-rich.git

Если хотите экспериментировать со своими коммитами — сделайте Fork каждого репо на GitHub и склонируйте уже свою копию.

6

Зависимости для rich-репо

В rich-репо стоит установить scikit-learn и scipy для скиллов кластеризации фидбэка и стат-тестов. Через uv (быстро):

# Установка uv
curl -LsSf https://astral.sh/uv/install.sh | sh

# Установка зависимостей
cd ~/Projects/fitflow-rich
uv venv
source .venv/bin/activate
uv pip install scikit-learn scipy numpy

Или через стандартный pip:

cd ~/Projects/fitflow-rich
python3 -m venv .venv
source .venv/bin/activate
pip install scikit-learn scipy numpy

Рекомендация: WSL2

Самый надёжный путь для Windows — установить WSL2 (подсистема Linux в Windows) и дальше следовать вкладке Linux. Запустите PowerShell от администратора:

wsl --install -d Ubuntu

После перезагрузки откроется терминал Ubuntu — все команды дальше выполняйте в нём.

Проблемы?

Шаг 1 не прошёл. Перезапустите терминал после установки. На macOS попробуйте python3.12 вместо python3. На Windows — проверьте галочку Add Python to PATH в установщике.
Перезапустите VS Code. Проверьте, что расширение включено (Extensions → Claude Code → Enable). Убедитесь, что у VS Code актуальная версия.
Шаг 4 — проверьте, что подписка активна или API-ключ скопирован целиком (формат sk-ant-api03-...). Перелогиньтесь в Claude Code: в панели расширения найдите Sign out и пройдите авторизацию заново.
Если на подписке — подождите час или поднимите тариф. Если на API — пополните баланс на console.anthropic.com.
Шаг 6 — активируйте виртуальное окружение (source .venv/bin/activate на macOS/Linux или .venv\Scripts\activate на Windows) перед запуском скиллов rich-репо.
Проверьте, что репо склонирован полностью: команда ls fitflow-bare/data/ должна показать fitflow.db. Если файла нет — заново склонируйте репо.
В Claude Code убедитесь, что выбрана правильная папка как workspace: File → Open Folder → выберите fitflow-bare или fitflow-rich.
